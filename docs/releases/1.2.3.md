# AJX 1.2.3

Running `ajx`, `ajx help`, or `ajx --help` now shows the AJX logo and installed
version above the command guide. Bare `ajx` exits successfully. Human-readable
`ajx doctor` output shows the same banner; `ajx doctor --json` remains a single
JSON document.

Installation and update downloads now show a progress bar when stderr is a
terminal, followed by a message when download completes and verification starts.
Redirected output stays plain, and JSON updates suppress progress animation.
The standalone installer also accepts `--no-progress`.

An update launched by an older AJX executable still uses that executable's
downloader and completion display for that invocation. The new behavior is
available in the new standalone installer and subsequent updates.
