# AJX 1.1.0

This release improves trial setup, evidence accuracy, and reporting.

- `ajx init --task` preserves the supplied prompt exactly. Initial setup also
  accepts a check name and a product version command.
- `ajx docs` provides offline CLI and artifact references. Doctor output makes
  readiness and shell configuration easier to understand.
- Skill counts are recorded separately from slash commands. Unknown inventory
  and command-error coverage remain explicitly unknown.
- Completed runs record their final stage states. Narration failures preserve
  their reason, and reporter evidence includes bounded tool inputs.
- Status output includes stage timing, and report Markdown renders more
  consistently.
- Repository hooks and CI scan outgoing history and metadata for secrets and
  accidental disclosure.

Reports still require review: generated explanations can contain unsupported
inferences, and reporting adds time and model calls after task execution.
Local context isolation is not a filesystem or network sandbox. Raw transcripts
and exported reports may contain private data and need review before sharing.

The CLI and matching skill are distributed together for macOS and Linux on
ARM64 and x86-64.
