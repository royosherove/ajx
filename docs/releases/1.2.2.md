# AJX 1.2.2

Installation and update completion now show an AJX logo with the installed
version directly underneath, followed by a boxed summary. Updates show the CLI
and skill outcome once. Fresh installations list their locations and relevant
next steps.

CLI-only updates no longer ask you to restart your agent session. Updates that
leave shell configuration unchanged no longer suggest reopening the terminal.
Download progress, backup notices, installation errors, and executable checks
remain in place.

`ajx update --json` keeps its structured result and build/skill metadata without
decorative output. Use `ajx version --json` to inspect those details separately.

An update launched by an older AJX executable still uses that executable's
completion display. The new display appears when using the updated CLI or the
new standalone installer.
