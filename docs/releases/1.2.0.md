# AJX 1.2.0

This release makes task input and recorded evidence easier for agents to use.

- `ajx init --task-file FILE` copies a nonempty UTF-8 task without changing its
  bytes and reports the saved prompt's SHA-256. It cannot be combined with
  `--task`. Existing files remain protected unless `--force` is supplied.
- `ajx init --max-budget-usd USD` sets a finite positive worker budget.
  Enforcement depends on the harness; reporting and nested trials are outside
  this worker limit.
- `ajx docs briefing`, `ajx docs environments`, and `ajx docs console` open
  bundled references offline. The artifact guide explains environment and
  process records, path roles, cleanup results, and budget evidence.
- Doctor and environment records distinguish requested configuration,
  prepared shell controls, and unobserved startup-file reads. AWS settings
  provenance records effective source paths and variable names without values.
- Skill inventories retain names and explicitly reported sources. An unknown
  source stays unknown; listing a skill does not establish activation or use.
- Runs print timestamped stage transitions, including long reporting stages.
  The native CLI keeps progress on stderr when `--json` is used.
- Default model wording consistently refers to the harness default.

These additions are available in the native CLI and Python fallback where
applicable. The bundled skill explains when to use task files and offline
references.

Requested controls do not establish filesystem or network isolation, forwarded
budget flags do not independently prove enforcement, and archive completion
does not prove that every external resource was removed. Keep raw process
records and transcripts private and review generated explanations against their
evidence.
