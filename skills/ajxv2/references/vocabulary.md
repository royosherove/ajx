Annotation vocabulary (describe only what the evidence shows; no label has a quota):

| Label | Meaning |
|---|---|
| 🧱 Wall | No available authorized path allowed continuation; the task stopped or needed a human. |
| 🚧 Roadblock | The documented path failed; an alternate path outside that documentation worked. |
| ↩️ Detour | The intended path eventually worked after extra retry or recovery steps. |
| ⏳ Wait | Waiting without a usable progress/completion signal. |
| 🚫 Dead End | A product-directed path did not achieve the needed result and was abandoned. |
| 🔀 Fork | Multiple plausible paths existed without a selection signal. |
| ❓ Wrong Turn | A selected path later proved wrong. Preserve the correction. |
| 🔴 Misdirection | Instructions or output pointed to an incorrect action or contradicted the actual result. |
| 👁️ Blind Spot | Relevant product information existed but was unavailable at the point of need. |
| 🚪 Gate | Human participation was required (headless runs record it as unresolved). |
| 🧭 Trust Decision | A choice between conflicting sources, or a change in which source informed an action. |
| 💸 Cost | A supported resource cost, or an explicit statement that it is unknown. |
| ✅ Delight | Concrete product behavior that helped achieve the task. |
